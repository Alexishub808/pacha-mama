# Pacha Mama

Botanical plant lexicon. Enter a botanical name, get a care datasheet: overview,
botanical facts, companion planting, planting instructions, care instructions —
all in German, with a plant photo pulled from Wikipedia.

The datasheet can be exported as Markdown for pasting into Joplin.

## Where this runs

This is the source of truth for a **Claude artifact**, not a standalone web app.

`askClaude()` in `src/PachaMama.jsx` calls `https://api.anthropic.com/v1/messages`
without an API key, because the artifact host injects credentials for that request.
Run the same file in a plain Vite or Next.js app and every search fails with an
authentication error. Making it standalone means adding a small backend that holds
the API key and forwards the request — the browser must never carry the key itself.

## Plant images

Three keyless, CORS-enabled sources are tried in order, each with both the
model-supplied search term and the botanical name:

1. Wikipedia article lead image — exact title first, then a site search
2. Wikimedia Commons file search, filtered to photographs
3. iNaturalist taxon photo

The first hit wins; a failing source never blocks the next. The caption under
the image names the source that answered, which doubles as a diagnostic when no
image appears.

Google Images is deliberately not among them. Its only official API needs a paid
key that a browser cannot hold safely, and Google indexes third-party pictures it
holds no right to sublicence — a credit line is not a licence. The three sources
above carry explicit free licences.

## Markdown export

The export dialog opens with the full Markdown text pre-selected, so `Ctrl+C` alone
is enough. The copy button tries two paths in order:

1. `document.execCommand("copy")` on the visible textarea — works inside the
   sandboxed artifact iframe.
2. `navigator.clipboard.writeText()` — the modern API, blocked in that iframe,
   kept as a fallback for other hosting contexts.

If both fail the button switches to "Strg+C drücken" and the text stays selected.
This ordering is deliberate: the modern API alone silently does nothing inside the
artifact sandbox.

## Note on plant data

Datasheets are generated by a language model and can be wrong. For anything that
matters — toxicity in particular, with children or pets around — verify against a
botanical reference.
