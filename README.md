# Pacha Mama

A single-file botanical plant encyclopaedia. Enter a Latin plant name, get a
datasheet: general facts, where and how to plant, how to maintain. Output is in
German.

No build step, no dependencies, no server. One HTML file you open in a browser.

## Use it

1. Download `index.html` (or clone this repository).
2. Open it in any browser — double-click works.
3. Paste an Anthropic API key once. **Merken** stores it in this browser's
   `localStorage`, so you only do this once per device.
4. Type a Latin name and press Enter.

Get a key at <https://console.anthropic.com/settings/keys>. API credit is
separate from a Claude subscription and is billed per request.

## What it does

- **Typo tolerance** — `lavandulla` resolves to *Lavandula angustifolia* and
  says so. An unknown name returns up to five clickable suggestions instead of
  an error.
- **Three tabs** — datasheet (family, height, flowering, hardiness, toxicity,
  companion planting), planting (soil, position, timing, fertiliser), care
  (watering, pruning, pests, overwintering).
- **Markdown export** — copy to clipboard or download a `.md` file, one per
  plant. Builds up a personal library for Obsidian, Joplin, Notion or a plain
  folder.
- **Plant photo** from a freely licensed source, with credit shown.

## Image sources

Tried in order, first hit wins; a failing source never blocks the next:

| Order | Source | How |
|-------|--------|-----|
| 0 | Wikimedia Commons | direct file name via `Special:FilePath`, no lookup request |
| 1 | Wikipedia | lead image of the article |
| 2 | Wikimedia Commons | file-namespace search, photos only |
| 3 | iNaturalist | CC-licensed observation photo, photographer credited |

Google Images is deliberately absent: it indexes third-party pictures it has no
right to sublicence, and its official API needs a paid key a browser cannot
hold safely.

## Privacy

The API key stays in `localStorage` on the device. The only outbound request
carrying it goes to `api.anthropic.com`. Image lookups carry no key. There is
no analytics, no tracking, no backend.

## Accuracy

Answers are generated by a language model. Treat them as a well-read starting
point, not as verified botanical authority — check anything that matters,
especially toxicity, before acting on it.

## Put it on the web (GitHub Pages)

Serving `index.html` from Pages gives a URL you can bookmark on a phone, so the
file no longer has to travel between devices.

1. Push this repository to GitHub, public.
2. **Settings → Pages → Build and deployment**. Source: *Deploy from a branch*.
   Branch: `main`, folder: `/ (root)`. **Save**.
3. Wait a minute. The URL appears on the same page:
   `https://YOUR-NAME.github.io/pacha-mama/`
4. Open it on the phone, paste the key once, press **Merken**.

The key lives in that browser's `localStorage`, per device. Publishing the page
does not publish the key — it was never in the file.

A public page means anyone can open it, but nobody can use it without their own
key, so it costs you nothing. Make the repository private if you would rather
not have it found at all; Pages then needs a paid plan.
